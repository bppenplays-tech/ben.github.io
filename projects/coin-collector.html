Coin Collector

Collect coins that spawn on a timer at random spots. The more you collect, the faster you move.

UnityC#

Gameplay

How it works

A PlayerController script reads input and moves the character in the direction the player chooses, with movement that feels fluid rather than snapping.

The Score script counts and displays a point every time a coin is collected, and once you've got enough coins it raises the player's speed. The coins come from a script I called Dynamic_Automated_Factory — a spawner that drops a coin at a random position every time its timer runs out.

Featured code

Dynamic_Automated_Factory.cs — spawn a coin on a timer

void Update()
{
    timer += Time.deltaTime;
    if (timer > SpawnTime)
    {
        SpawnCoin();
        timer = 0f;
    }
}

void SpawnCoin()
{
    float rx = Random.Range(-8f, 8f);
    float ry = Random.Range(-4.5f, 4.5f);
    Vector3 pos = new Vector3(rx, ry, 0);
    Instantiate(coinprefab, pos, Quaternion.identity);
}

The timer-then-spawn pattern turns up again in nearly every game after this one — pipes, fish, asteroids all use the same shape.
